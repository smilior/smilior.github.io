ボタン

02

リンク

本文中のリンクは color.text.primary + 下線で表現する。hover でアクセント色に遷移する。

本文のなかに 普通のインラインリンク が含まれる例。フォーカス時は アウトライン を表示する。

仕様

  • 下線は常時表示（色は color.border.default）。
  • hover で文字色・下線色ともに color.text.tertiary。
  • focus-visible は他コンポーネントと同じ 2px solid 枠。
  • 外部リンクには rel="noopener noreferrer" を付与する。

05

バッジ

ステータスやカテゴリを示す小さな識別子。radius.sm（ピル）を使用する。

Default Draft Published

使い分け

  • Default — カテゴリ・タグ。
  • Accent — レビュー中など注意を引きたい状態。
  • Solid — 確定した状態（公開済 等）。
